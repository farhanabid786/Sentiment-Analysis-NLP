How the workflow fits together

The page is structured so visitors can understand the app before they use it. Each step below matches the flow inside the Flask application.

01

User input

A visitor enters a review or short text in the input field.

02

Text cleaning

The app removes punctuation, lowercases the text, and lemmatizes words.

03

Vectorization

The cleaned text is transformed into TF-IDF features using the saved vectorizer.

04

Prediction

The model returns a sentiment label and the result is displayed on the page.
